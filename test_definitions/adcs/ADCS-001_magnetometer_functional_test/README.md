# ADCS-001 — Magnetometer Functional Test

## Overview

This folder contains the definition files for the ADCS-001 test.

The purpose of this test is to verify the basic functionality of the magnetometer used by the ADCS subsystem.

## Test Information

| Field | Value |
|---|---|
| Test ID | ADCS-001 |
| Test name | Magnetometer Functional Test |
| Subsystem | ADCS |
| Component | Magnetometer |
| Status | Draft |
| Version | v0.1 |
| Responsible | TBD |

## Files

| File | Description |
|---|---|
| `ADCS-001_magnetometer_functional_test_form.tex` | Editable LaTeX source file used to generate the test form. This file should be modified only when the structure or content of the form needs to be updated. |
| `ADCS-001_magnetometer_functional_test_fillable.pdf` | Fillable PDF form to be used during or after the execution of the test. This is the file that should be filled by the person performing the test. |
| `procedure.pdf` | Placeholder PDF for the test procedure. It will be replaced by the final step-by-step procedure document when it becomes available. |



## Notes

The `.tex` file is the editable source of the form and should be kept for version control and future updates.

The fillable PDF is the practical form used during the test execution.
